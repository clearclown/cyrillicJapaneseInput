Pismo - プライバシーポリシー

最終更新日: 2025年11月8日

重要: Pismo は、ユーザーの入力内容を一切収集、保存、送信しません。すべての処理はデバイス内で完結します。

1. はじめに

Pismo（以下「本アプリ」）は、キリル文字配列を使用して日本語ひらがなを入力するための IME（Input Method Editor）アプリです。本プライバシーポリシーは、本アプリがユーザーの個人情報をどのように取り扱うかを説明します。

2. 収集する情報

本アプリは、ユーザーの個人情報を一切収集しません。

  • 入力された文字や文章の内容
  • キーボードの使用履歴
  • 変換候補の選択履歴
  • 位置情報
  • 連絡先情報
  • その他の個人を特定できる情報

上記のいずれも収集、保存、送信されることはありません。

3. データの処理

本アプリは、以下の特徴を持ちます：

  • オフライン動作: すべての変換処理はデバイス内で実行されます
  • ネットワーク通信なし: インターネット接続を必要とせず、外部サーバーとの通信は一切行いません
  • ローカルストレージのみ: 設定情報（選択中のキーボードプロファイル等）のみがデバイス内に保存されます

4. 保存される情報

本アプリは、以下の設定情報のみをデバイス内に保存します：

  • 現在選択中のキーボードプロファイル（ロシア語、セルビア語、ウクライナ語など）
  • アプリの設定項目（ハプティックフィードバックの有効/無効など）

これらの情報は、ユーザーのデバイス内にのみ保存され、外部に送信されることはありません。

5. 第三者との情報共有

本アプリは、いかなる第三者とも情報を共有しません。広告ネットワーク、アナリティクスサービス、その他の第三者サービスは使用していません。

6. 権限について

本アプリは、IME として機能するために必要な最小限の権限のみを要求します：

  • 入力メソッド権限: キーボードとして動作するために必要です

これらの権限は、アプリの基本機能を提供するためにのみ使用され、データ収集には使用されません。

7. セキュリティ

ユーザーの入力内容は、デバイスのメモリ内でのみ一時的に処理され、変換完了後は即座に破棄されます。ストレージへの書き込みや、ネットワーク経由での送信は一切行いません。

8. 子供のプライバシー

本アプリは、13歳未満の子供を含むすべての年齢層の方が安全に使用できます。個人情報を収集しないため、特別な保護者の同意は必要ありません。

9. プライバシーポリシーの変更

本プライバシーポリシーを更新する場合は、このページに変更内容を掲載します。重要な変更がある場合は、アプリ内で通知します。

Privacy Policy - English

Last Updated: November 8, 2025

Important: Pismo does not collect, store, or transmit any user input. All processing is performed locally on your device.

1. Introduction

Pismo ("the App") is an IME (Input Method Editor) application that enables Japanese hiragana input using Cyrillic keyboard layouts. This Privacy Policy explains how the App handles user information.

2. Information We Collect

The App does not collect any personal information.

  • Typed text or content
  • Keyboard usage history
  • Conversion candidate selection history
  • Location data
  • Contact information
  • Any other personally identifiable information

None of the above are collected, stored, or transmitted.

3. Data Processing

The App features:

  • Offline Operation: All conversion processing occurs on your device
  • No Network Communication: No internet connection required; no communication with external servers
  • Local Storage Only: Only settings (e.g., selected keyboard profile) are stored locally

4. Stored Information

The App stores only the following settings on your device:

  • Currently selected keyboard profile (Russian, Serbian, Ukrainian, etc.)
  • App preferences (haptic feedback on/off, etc.)

This information is stored only on your device and never transmitted externally.

5. Third-Party Sharing

The App does not share information with any third parties. No advertising networks, analytics services, or other third-party services are used.

6. Permissions

The App requests only the minimum permissions necessary to function as an IME:

  • Input Method Permission: Required to operate as a keyboard

These permissions are used solely to provide core functionality, not for data collection.

7. Security

User input is processed temporarily in device memory only and immediately discarded after conversion. No writing to storage or network transmission occurs.

8. Children's Privacy

The App is safe for all ages, including children under 13. Since no personal information is collected, no special parental consent is required.

9. Changes to This Privacy Policy

Updates to this Privacy Policy will be posted on this page. Significant changes will be notified within the App.
