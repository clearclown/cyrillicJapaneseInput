## 詳しい説明（4000文字以内）

### 🌏 多言語話者のための新しい日本語入力体験

Pismo は、キリル文字配列のキーボードで日本語のひらがなを入力できる革新的な IME（Input Method Editor）アプリです。ロシア語、セルビア語、ウクライナ語など、複数のキリル文字言語に対応しています。

### ✨ 主な機能

**複数のキリル文字配列に対応**
- ロシア語標準配列
- セルビア語キリル配列
- ウクライナ語配列
- 分析的なデバッグモード

**スマートな変換システム**
- キリル文字の音韻から日本語ひらがなへの直接変換
- 二段階の正規化マッピングで高精度な変換を実現
- 促音（っ）や撥音（ん）にも対応

**プライバシー重視**
- 完全オフライン動作
- ユーザーの入力内容を一切収集しない
- 外部サーバーとの通信なし
- すべての処理がデバイス内で完結

**快適な入力体験**
- Modern Material Design に基づいた美しい UI
- スムーズなアニメーション
- ハプティックフィードバック対応
- 軽量で高速な動作

### 🎯 こんな方におすすめ

- ロシア語、セルビア語、ウクライナ語などのキリル文字言語を母語とする日本語学習者

- 言語学や音韻論に興味がある方

### 📱 使い方

1. アプリをインストール
2. Android の設定 → システム → 言語と入力 → 仮想キーボードで Pismo を有効化
3. テキスト入力時にキーボード切り替えボタンから Pismo を選択
4. キリル文字で日本語を入力開始！

### 🔒 安全性とプライバシー

Pismo は、ユーザーのプライバシーを最優先に設計されています：

## Full Description (4000 characters)

### 🌏 A New Japanese Input Experience for Multilingual Speakers

Pismo is an innovative IME (Input Method Editor) app that enables Japanese hiragana input using Cyrillic keyboard layouts. It supports multiple Cyrillic languages including Russian, Serbian, and Ukrainian.

### ✨ Key Features

**Multiple Cyrillic Layout Support**
- Russian standard layout
- Serbian Cyrillic layout
- Ukrainian layout
- Analytical debug mode

**Smart Conversion System**
- Direct conversion from Cyrillic phonetics to Japanese hiragana
- Two-stage normalized mapping for high accuracy
- Support for special characters (促音っ, 撥音ん)

**Privacy-Focused**
- Completely offline operation
- No collection of user input
- No external server communication
- All processing done on-device

**Comfortable Input Experience**
- Beautiful UI based on Modern Material Design
- Smooth animations
- Haptic feedback support
- Lightweight and fast

### 🎯 Perfect For

- Japanese learners whose native language uses Cyrillic script
- Multilingual speakers working with multiple Cyrillic languages
- Those interested in linguistics and phonology
- Anyone wanting to try a unique input method

### 📱 How to Use

1. Install the app
2. Enable Pismo in Android Settings → System → Languages & input → Virtual keyboard
3. Select Pismo from the keyboard switcher when typing
4. Start typing Japanese using Cyrillic characters!

### 🔒 Safety and Privacy

Pismo is designed with user privacy as the top priority:
- ✅ No logging of input content
- ✅ No internet connection required
- ✅ No ads
- ✅ No tracking
- ✅ Completely free

### 🌟 Technical Features

- High-performance core engine implemented in Rust
- Modern UI with Jetpack Compose
- Phonology-based conversion algorithm
- Settings stored only on device

### 📚 Conversion Examples

**Russian Layout:**
- КА → か
- КИ → き
- ЧИ → ち
- КЯ → きゃ

**Serbian Layout:**
- КА → か
- КИ → き
- Ћ → ち
- КЈА → きゃ

Pismo is completely free to use. No in-app purchases or ads.

We welcome your feedback, suggestions, and bug reports through the in-app feedback feature or email. Your input helps make Pismo better.

### 🔄 Future Plans

- Katakana input support

- Theme customization
- Additional language profiles
