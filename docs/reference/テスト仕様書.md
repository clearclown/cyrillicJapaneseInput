## 1. テスト方針

### 1.1 テストの目的

- 多言語バリアント（RUS, UKR, BEL, BUL, SRB）におけるキリル文字→かな変換の正確性を保証する。
- Rust Core FFI を介した変換フローの安定性を確認する。

### 1.2 テスト戦略

- **Unit Tests (Rust)**: 入力ステートマシン、かな変換ロジック、辞書引きロジックのテスト。
- **Unit Tests (Swift)**: UIロジック、InputManagerの挙動、設定管理のテスト。
- **Integration Tests**: 実機/シミュレーターでのE2Eテスト。

## 3. Rust Core FFI テスト

| テストID | テスト内容 | 期待結果 |
|---|---|---|

| FFI-CONFIG-001 | プロファイル切り替え (RUS -> UKR) | マッピングロジックが即座に変更される |

- `mapping_tests.rs`: 各言語バリアントのCSVロードと文字変換の単体テスト。
- `input_state_tests.rs`: "k" -> "k" (wait) -> "ka" (complete) のようなステートマシンのテスト。

## 4. 統合テスト (E2E)

### 4.1 シナリオ: 標準入力フロー (基本機能確認)

**目的**: 標準的なローマ字入力（キリル文字版）の一連の流れを網羅的に検証する。入力→変換→候補選択→確定、および編集操作を含む。
**前提**: 言語プロファイルは `Russian Standard (RUS)` を使用。

#### シナリオ詳細

| Step | 操作 (Input) | 期待されるバッファ表示 (Buffer) | 期待される動作 (Behavior) | 備考 |
|---|---|---|---|---|
| **1. 基本文入力** | "こんにちは" (Konnichiwa) を入力 | | | |
| 1-1 | `К` (K) | `к` | 入力待機 (子音) | |
| 1-2 | `о` (o) | `こ` | かな変換完了 ("Ko" -> "こ") | |
| 1-3 | `н` (n) | `こн` | 入力待機 (子音) | |
| 1-4 | `н` (n) | `こん` | 撥音変換 ("nn" -> "ん") | |
| 1-5 | `и` (i) | `こんに` | かな変換 ("ni" -> "に") | |
| 1-6 | `ч` (ch) | `こんにч` | 入力待機 (子音) | |
| 1-7 | `и` (i) | `こんにち` | かな変換 ("chi" -> "ち") | |
| 1-8 | `х` (h) | `こんにちх` | 入力待機 (子音) | |
| 1-9 | `а` (a) | `こんにちは` | かな変換 ("ha" -> "は") | Greeting spelling "ha" |
| **2. 変換候補** | Spaceキーを押下 | `こんにちは` (下線等) | 候補バーに候補を表示 | |
| 2-1 | (Space) | | 候補: [こんにちは, 今日は, ...] | 予測変換または通常変換 |
| 2-2 | "こんにちは" をタップ | (空) | テキストフィールドに "こんにちは" が確定挿入される | バッファクリア |
| **3. 促音入力** | "きって" (Kitte) を入力 | | | |
| 3-1 | `К` (K) | `к` | | |
| 3-2 | `и` (i) | `き` | | |
| 3-3 | `т` (t) | `きт` | | |
| 3-4 | `т` (t) | `きっт` | 促音生成 ("tt" -> "っt") | |
| 3-5 | `э` (e) | `きって` | かな変換 ("te" -> "て") | |
| 3-6 | Returnキーを押下 | (空) | "きって" が確定挿入される | |
| **4. 編集操作** | 入力中の訂正 (Backspace) | | | |
| 4-1 | `К` (K) | `к` | | |
| 4-2 | `а` (a) | `か` | | |
| 4-3 | Backspace | (空) | 文字 "か" が削除される | iOS標準動作に準拠 |
| 4-4 | `К` (K) | `к` | | |
| 4-5 | Backspace | (空) | 文字 "к" が削除される | 未確定バッファの削除 |
| **5. 長音・特殊** | "とうきょう" (Tokyo) | | | |
| 5-1 | `Т` (T) | `т` | | |
| 5-2 | `о` (o) | `と` | | |
| 5-3 | `о` (o) | `とー` | 母音連続 -> 長音変換 (設定依存だが基本は長音) | 要件定義 "ー: 母音を2回" に準拠 |
| 5-4 | `к` (k) | `とーк` | | |

| 5-6 | `о` (o) | `とーきょー` | | |

### 4.2 シナリオ: 多言語切り替え入力

1. **Step 1**: RUSプロファイルを選択。
2. **Input**: `К` + `А` -> "か" が表示されること。
3. **Step 2**: UKRプロファイルに切り替え。
4. **Input**: `К` + `І` -> "き" が表示されること。
5. **Step 3**: BULプロファイルに切り替え。
6. **Input**: `К` + `Ъ` -> "く" が表示されること。
