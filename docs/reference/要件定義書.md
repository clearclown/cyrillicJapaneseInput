# Pismo - キリル文字日本語IME 要件定義書

**バージョン**: 1.1.0
**作成日**: 2025-11-23
**ステータス**: 改訂版

---

## 1. プロジェクト概要

### 1.1 目的

キリル文字配列を使用して日本語（平仮名・漢字）を入力できるIME（Input Method Editor）を開発する。
`azooKey` をベースとし、入力エンジン部分は Rust で実装されたコアロジックと連携するアーキテクチャを採用する。

### 1.2 基本コンセプト

**「日本語ローマ字入力のローマ字部分をキリル文字に置き換える」**

#### 入力フロー
```
キリル文字入力 → 音韻キー → 平仮名 → 漢字変換
К + А → "ka" → "か" → "家" / "可愛い" 等
```

### 1.3 対象ユーザー

- キリル文字圏（ロシア、ウクライナ、ベラルーシ、ブルガリア、セルビア等）の日本語学習者
- 日本語話者でキリル文字を学習したい人
- 多言語環境での日本語入力を必要とする人

## 2. 機能要件

### 2.1 サポート言語プロファイル

以下の言語バリアントをサポートし、それぞれに応じた文字マッピングを提供する。

#### 2.1.1 言語バリアント定義
| ID | 言語 | 略称 | 特徴 |
|---|---|---|---|
| `russian` | ロシア語 (標準) | RUS | 基礎となるマッピング (ЙЦУКЕН) |
| `ukrainian` | ウクライナ語 | UKR | `І`, `Ї`, `Є`, `Ґ` を使用 |
| `belarusian` | ベラルーシ語 | BEL | `І`, `Ў` を使用 |
| `bulgarian` | ブルガリア語 | BUL | `Ъ` (u音), `Е` (e音) の特殊マッピング |
| `serbian` | セルビア語 | SRB | `Ћ`, `Ј`, `Љ`, `Њ`, `Џ` を使用 |

#### 2.2.3 特殊規則 (Special Rules)

| 日本語 | キリル文字表記 (Base) | 分析モード (Analytical) | 備考 |
|---|---|---|---|
| **ん** | н | н | p, b, m の前では м になる異音（Allophone）が存在しうるが、入力上は `н` で統一 |
| **っ** (促音) | (後続の子音を重ねる) <br> 例: Киттэ (切手) | ъ (硬音符) <br> 例: Киътэ | 子音連打で入力待機状態とする |
| **ー** (長音) | (前の母音を重ねる) <br> 例: Тоокёо (東京) | (同左) | |
| **んあ** (音節分離) | н'а (アポストロフィ) | нъа (硬音符) | `na` (な) と `n-a` (んあ) を区別するため |
| **んや** (音節分離) | н'я (アポストロフィ) | нъя (硬音符) | `nya` (にゃ) と `n-ya` (んや) を区別するため |

### 2.3 漢字変換

#### 2.3.1 変換エンジン
- **Frontend (Swift)**: `InputManager` が入力を受け取り、Rust Core へ渡す。
- **Backend (Rust)**: `Rust Core` がキリル文字→かな変換（ローマ字変換ロジックの拡張）、およびかな漢字変換（辞書引き）を担当する。

#### 2.3.2 変換モード
- **手動変換**: Space キーで変換。
- **ライブ変換**: 入力中に自動変換（オプション）。

## 3. 非機能要件

### 3.1 パフォーマンス
- 入力遅延: < 10ms
- 変換速度: < 50ms

### 3.2 デザイン
- iOS標準キーボード準拠。
- 言語プロファイルごとのキーボード配列切り替え (ЙЦУКЕН, ЉЊЕРТ, BDS等)。

---

## 4. システムアーキテクチャ

### 4.1 技術スタック

#### 4.1.1 iOS (Frontend)
- **言語**: Swift 5.9+
- **フレームワーク**: UIKit (Keyboard Extension), SwiftUI
- **役割**: UI描画、入力イベントのキャプチャ、設定管理

#### 4.1.2 Core Logic (Backend)
- **言語**: Rust
- **役割**:
  - **Input State Machine**: キリル文字入力のバッファ管理、ローマ字(キリル)→かな変換ステート管理。
  - **Kana-Kanji Converter**: かな→漢字変換、予測変換、辞書管理。
- **連携**: Rust FFI (Foreign Function Interface) を使用して Swift から呼び出す。

### 4.2 データフロー

```
[ユーザー入力 (キリル文字)]
    ↓
[Swift: KeyboardViewController]
    ↓
[Swift: InputManager]
    ↓ (FFI Call)
[Rust: InputStateMachine] ← マッピング定義 (CSV/JSON) を参照
    ↓ (かな文字列)
[Rust: KanaKanjiConverter]
    ↓ (変換候補)
[Swift: CandidateBar]
```
