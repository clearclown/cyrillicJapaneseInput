## О приложении Pismo

**Pismo** — это клавиатура для iOS/iPadOS, которая позволяет вводить японский язык (хирагана и катакана) с помощью кириллицы.

Название «Pismo» происходит от славянского слова, означающего «письмо» или «письменность», что символизирует связь между кириллицей и японским языком.

## О кириллице

Кириллица — это система письменности, которая развилась в Первом Болгарском царстве в IX веке. Она была создана на основе греческого алфавита для передачи фонетики славянских языков.

Сегодня кириллица используется во многих языках:

| Язык | Регион | Особенности |
|------|--------|-------------|
| Русский | Россия | 33 буквы |
| Украинский | Украина | 33 буквы (включая І, Ї, Є, Ґ) |
| Белорусский | Беларусь | 32 буквы (включая Ў, І) |
| Болгарский | Болгария | 30 букв (родина кириллицы) |
| Сербский | Сербия | 30 букв (также используется латиница) |
| Другие | Монголия, Казахстан и др. | Уникальные расширения алфавита |

**Важно:** Это приложение не имеет политической направленности. Оно создано из чистого интереса к кириллице как системе письменности и для поддержки изучения языков.

## Для кого это приложение

- **Для японцев, интересующихся кириллицей**
  - Изучающие славянские языки
  - Изучающие тексты Восточной православной церкви
  - Любители русской и украинской литературы
  - Интересующиеся лингвистикой и письменностью

- **Для пользователей кириллицы, изучающих японский язык**
  - Для тех, кто привык к кириллической клавиатуре и хочет вводить японский текст

## Основные функции

- **Поддержка 5 языков**
  - Русский (Русский)
  - Украинский (Українська)
  - Белорусский (Беларуская)
  - Болгарский (Български)
  - Сербский (Српски)

- **Конвертация в реальном времени**
  - Ввод кириллицей → мгновенное преобразование в японский (хирагана/катакана)
  - Пример: `привет` → `ぷりゔぇっと`

- **Высокоточный движок конвертации**
  - Использует движок azooKey
  - Включает нейронную систему преобразования кана-кандзи «Zenzai»

- **Конфиденциальность**
  - Данные ввода не отправляются на сервер
  - Полностью работает офлайн
