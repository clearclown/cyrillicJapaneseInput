## Description

### Japanese (日本語)

Pismoは、キリル文字を使って日本語を入力できる革新的なiOSキーボードアプリです。

【主な機能】
• キリル文字からひらがなへのリアルタイム変換
• 5つのキリル文字言語に対応（ロシア語、ウクライナ語、ブルガリア語、セルビア語、ベラルーシ語）
• ライブ変換機能で入力しながら漢字変換
• QWERTYレイアウトで馴染みやすい操作感
• ダークモード対応
• プライバシー重視設計（フルアクセス不要で基本機能が使用可能）

【こんな方におすすめ】
• キリル文字キーボードに慣れている方
• ロシア語圏出身で日本語を学習中の方
• 日本語とキリル文字言語を併用する方
• 新しい入力方法を試したい方

【変換例】
Привет → ぷりゔぃぇっと
Москва → もすくゔぁ
Коннитиха → こんにちは

【オープンソース】
Pismoはオープンソースプロジェクトです。GitHubでソースコードを公開しています。

### English

Pismo is an innovative iOS keyboard app that lets you type Japanese using Cyrillic characters.

【Key Features】
• Real-time conversion from Cyrillic to Hiragana
• Support for 5 Cyrillic languages (Russian, Ukrainian, Bulgarian, Serbian, Belarusian)
• Live conversion for instant kanji suggestions
• Familiar QWERTY layout
• Dark mode support
• Privacy-focused design (basic features work without Full Access)

【Perfect For】
• Users familiar with Cyrillic keyboards
• Russian speakers learning Japanese
• Bilingual users of Japanese and Cyrillic languages
• Anyone looking for a new input method

【Conversion Examples】
Привет → ぷりゔぃぇっと
Москва → もすくゔぁ
Коннитиха → こんにちは

【Open Source】
Pismo is an open-source project. Source code available on GitHub.

### Russian (Русский)

Pismo — инновационное приложение-клавиатура для iOS, позволяющее вводить японский текст с помощью кириллицы.

【Основные функции】
