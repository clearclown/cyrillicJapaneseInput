## App Information

### Name
```
Pismo - Cyrillic Japanese Keyboard
```

### Subtitle
```
Type Japanese with Cyrillic layouts
```

### Description (English)
```
Pismo is a unique keyboard app that allows you to type Japanese (Hiragana and Katakana)
using Cyrillic keyboard layouts. Perfect for:

• Japanese learners familiar with Cyrillic keyboards
• Cyrillic keyboard users studying Japanese
• Researchers of Slavic languages and Japanese
• Anyone interested in the connection between scripts

FEATURES:
• Multiple Cyrillic layouts: Russian, Ukrainian, Belarusian, Bulgarian, Serbian
• Real-time conversion to Hiragana and Katakana
• Predictive Japanese input
• Works completely offline
• No data collection - your privacy is protected

ABOUT CYRILLIC:
The Cyrillic script, originating in 9th century Bulgaria, is used by over 250 million
people worldwide. Pismo celebrates this rich writing tradition while bridging it with
the beauty of Japanese script.

Note: This app takes no political stance. It is purely a linguistic and educational tool
celebrating the diversity of writing systems.

Based on azooKey by Keita Miwa (ensan).
```

### Notes for Reviewer
```
This is a keyboard extension app. To test:

1. Install the app
2. Go to Settings → General → Keyboard → Keyboards
3. Add "Pismo" keyboard
4. Open any text field and switch to Pismo keyboard
5. Type using Cyrillic characters to see Japanese conversion

The keyboard works offline and does not require any account or login.
No Full Access permission is required for basic functionality.
```
