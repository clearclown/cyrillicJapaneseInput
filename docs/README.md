## 📝 ドキュメントの執筆・メンテナンス

### ドキュメント更新時のガイドライン

1. **最終更新日を記載**
   - 各ドキュメントの末尾に `**最終更新**: YYYY-MM-DD` を記載

2. **バージョン管理**
   - 大きな変更の場合はバージョン番号を更新（例: v1.0 → v1.1）
   - 変更履歴を文書内に記載

3. **リンクの整合性**
   - 内部リンクが正しく機能するか確認
   - このREADME.mdも更新

4. **対象読者の明記**
   - 初心者向け / 中級者向け / 上級者向けを明確に

### 新しいドキュメントを追加する場合

1. 適切なカテゴリを選択:
   - 設計・仕様書
   - 開発計画書
   - デプロイ手順書
   - 分析・比較レポート

2. ファイル命名規則:
   - 日本語OK（既存に合わせる）
   - 英語の場合: `snake_case.md`

3. このREADME.mdに追加:
   - 適切なテーブルにエントリを追加
   - 検索しやすいようキーワードインデックスも更新

## ❓ FAQ

### Q1: どのデプロイガイドを読めばいいですか？

**A**: 初心者の方は「初心者向けコマンドライン完全ガイド」を推奨します：
- [iOS_デプロイ_初心者向けコマンドライン完全ガイド](./iOS_デプロイ_初心者向けコマンドライン完全ガイド.md)
- [Android_デプロイ_初心者向けコマンドライン完全ガイド](./Android_デプロイ_初心者向けコマンドライン完全ガイド.md)

これらは環境構築から詳細に説明しており、期待される出力も記載されています。

### Q2: macOSを持っていませんが、iOS開発はできますか？

**A**: iOS開発の最終段階（Xcodeでのビルド、App Store申請）には**macOSが必須**です。詳細は以下を参照：
- [iOS_デプロイ_初心者向けコマンドライン完全ガイド](./iOS_デプロイ_初心者向けコマンドライン完全ガイド.md) § macOSがいつ必要か？
- [iOS開発環境コスト比較](./iOS開発環境コスト比較.md) - Mac購入以外の選択肢

### Q3: Android開発はどのOSでできますか？

**A**: **Windows、macOS、Linux のいずれでも開発可能**です。詳細は：
- [Android_デプロイ_初心者向けコマンドライン完全ガイド](./Android_デプロイ_初心者向けコマンドライン完全ガイド.md) § 開発環境について

### Q4: 実装状況はどこで確認できますか？

**A**: 以下の2つを参照してください：
- [README.md](../README.md) § 4. プロジェクト開発状況
- [実装状況分析レポート](./実装状況分析レポート.md)
