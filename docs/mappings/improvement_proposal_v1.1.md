## 1. wo→を マッピングの追加（必須）

### 現状の問題
- `О` は `お` にマッピングされている
- `を` (助詞) を入力する方法がない
- コメント: `"wo" (を) is intentionally omitted - О maps to お (o)`

### 解決策
**Во → を** を追加

理由:
- わ行のパターンに一致: Ва=わ, Ви=ゐ, Вэ=ゑ, **Во=を**
- В (v) は日本語の w 音を表す
- 論理的で覚えやすい

### CSV更新 (cyrillic_mapping_seion.csv)
```csv
wo,を,Во,Во,Ўо,Во,Во
```
※ベラルーシ語は Ў (短いu) を使用

## 2. ダ行濁音の追加

### 現状の問題
- だ (da) = Да ✓
- ぢ (di) = Дзи (じ と同じ) ← 区別できない
- づ (du) = Дзу (ず と同じ) ← 区別できない
- で (de) = Дэ ✓
- ど (do) = До ✓

ぢ・づ を明示的に入力する方法がない。

### 解決策
**Ди → ぢ**, **Ду → づ** を追加

現状:
- Ди = でぃ (外来語)
- Ду = どぅ (外来語)

変更後:
- Ди = ぢ (優先)、Дьи = でぃ (外来語)
- Ду = づ (優先)、Дьу = どぅ (外来語)

または、外来語を維持して別のマッピング:
- Дьи = ぢ (soft sign で濁音を示す)
- Дьу = づ

### 推奨案（互換性を維持）
| ローマ字 | かな | 新規キリル | 既存キリル | 備考 |
|---------|------|-----------|-----------|------|
| di | ぢ | Дьи | Дзи (じと共用) | soft sign で区別 |
| du | づ | Дьу | Дзу (ずと共用) | soft sign で区別 |

### CSV更新 (cyrillic_mapping_dakuten.csv に追加)
```csv
di,ぢ,Дьи,Дьі,Дьі,Дьи,Дьи
du,づ,Дьу,Дьу,Дьу,Дьъ,Дьу
```
