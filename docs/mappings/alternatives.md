# Alternative Input Methods

Some keyboards lack certain Cyrillic characters. These alternative mappings provide workarounds.

## Ё Alternatives (for keyboards without Ё key)

The character Ё is used for the Japanese よ (yo) sound. For keyboards without a dedicated Ё key:

### Using ЙО as alternative

| Standard | Alternative | Hiragana |
|----------|-------------|----------|
| Ё | ЙО | よ |
| КЁ | КЙО | きょ |
| СЁ | СЙО | しょ |
| НЁ | НЙО | にょ |
| ХЁ | ХЙО | ひょ |
| МЁ | МЙО | みょ |
| РЁ | РЙО | りょ |
| ГЁ | ГЙО | ぎょ |
| ДЗЁ | ДЗЙО | じょ |
| БЁ | БЙО | びょ |
| ПЁ | ПЙО | ぴょ |

### Keyboard Layout Solution

In the iOS keyboard, Ё is placed as the **default** key with Е available on **flick up**.

This design choice was made because:
1. Ё is essential for Japanese input (よ sound)
2. Е is less frequently needed in this context
3. Users can configure this preference (future feature)

## Ъ Alternatives (for keyboards without Ъ key)

The hard sign Ъ is used for:
1. Small kana prefix (ъа → ぁ, ъя → ゃ, etc.)
2. Separator for ん + vowel (нъа → んあ)

### Using Apostrophe as alternative

| Standard | Alternative | Output |
|----------|-------------|--------|
| ЪА | 'А | ぁ (small a) |
| ЪЯ | 'Я | ゃ (small ya) |
| ЪЮ | 'Ю | ゅ (small yu) |
| ЪЁ | 'Ё | ょ (small yo) |
| НЪА | Н'А | んあ |

### Keyboard Layout Solution

In the iOS keyboard, Ъ is available on **flick up** from the Ь key.

## Ху as Alternative for Фу (ふ)

On Russian keyboards, users might intuitively type Ху for the "hu/fu" sound instead of Фу.

| Standard | Alternative | Hiragana |
|----------|-------------|----------|
| Фу | Ху | ふ |

Both inputs produce ふ.

## Small Kana (小書き仮名)

Small kana are input using the Ъ (or ') prefix:

| Input | Output | Name |
|-------|--------|------|
| ЪА / 'А | ぁ | small a |
| ЪИ / 'И | ぃ | small i |
| ЪУ / 'У | ぅ | small u |
| ЪЭ / 'Э | ぇ | small e |
| ЪО / 'О | ぉ | small o |
| ЪЯ / 'Я | ゃ | small ya |
| ЪЮ / 'Ю | ゅ | small yu |
| ЪЁ / 'Ё | ょ | small yo |
| ЪЦ / 'Ц | っ | small tsu |
| ЪВА / 'ВА | ゎ | small wa |
| ЪКА / 'КА | ゕ | small ka |
| ЪКЭ / 'КЭ | ゖ | small ke |
