## 1. テスト方針

### 1.1 テストの目的

**最優先事項**: 本プロジェクトにおいてテストは最高優先度である。

- Cyrillic → 平仮名 → 漢字変換の正確性を保証
- iOS標準キーボードと同等のUX品質を実現
- 全5言語プロファイルでの動作保証
- パフォーマンス要件の達成確認
- リグレッションの防止

### 1.2 テスト戦略

```
Test Pyramid:
  ┌─────────────┐
  │  E2E Tests  │  ← 主要フロー100%カバー
  │   (10%)     │
  ├─────────────┤
  │Integration  │  ← 全プロファイル × 全パターン
  │Tests (30%)  │
  ├─────────────┤
  │ Unit Tests  │  ← 80%以上のカバレッジ
  │   (60%)     │
  └─────────────┘
```

### 1.3 テストカバレッジ目標

| テスト種別 | カバレッジ目標 | 測定方法 |
|-----------|---------------|----------|
| ユニットテスト | 80%以上 | XCTest Coverage / JaCoCo |
| UIテスト | 主要フロー100% | XCUITest / Espresso |
| 統合テスト | 全プロファイル × 全パターン | 手動マトリックス |
| パフォーマンステスト | 全項目達成 | Instruments / Profiler |

### 1.4 テスト環境

#### iOS
- **実機**: iPhone 15 Pro (iOS 17.0+), iPhone SE 3rd (iOS 16.0+)
- **シミュレーター**: iPhone 15, iPhone 14, iPhone SE
- **Xcode**: 15.0+
- **Swift**: 5.9+

#### Android
- **実機**: Pixel 8 (Android 14+), Galaxy S23 (Android 13+)
- **エミュレーター**: Pixel 7 API 33, Pixel 5 API 30
- **Android Studio**: Hedgehog+
- **Kotlin**: 1.9+
